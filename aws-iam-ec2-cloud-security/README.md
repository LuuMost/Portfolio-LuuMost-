# Cloud Security with AWS IAM & EC2

**Author:** Richard Lutendo Mudau

**Skills:** AWS IAM · Amazon EC2 · Cloud Security · Least-Privilege Access · JSON Policies

---

## Project Overview

Hands-on cloud security project on AWS, completed through the NextWork guided program. The goal: understand how access control works in AWS and apply the **principle of least privilege** to real resources.

## What I Did

- **Created IAM users and groups** — structured access through groups rather than attaching permissions to individual users
- **Wrote custom JSON IAM policies** — enforced least-privilege access, granting only the permissions each identity actually needs
- **Launched and secured EC2 instances** — applied IAM group-based permissions to control access to compute resources

## Outcome

100% of permissions administered through groups under least-privilege — no standing access beyond what each user required, and secured EC2 instances launched under those controls.
